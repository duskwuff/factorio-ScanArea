Scan Area
=========

Adds a tool to the toolbar to chart or unchart an area of the map, unlocked by
launching at least one rocket into space.

(Uncharting an area only makes chunks invisible to the player. It does not
delete them from the map.)

Includes a setting which automatically scans the area around the viewport while
remotely viewing the map. This emulates a similar feature in Space Exploration,
and is disabled if that mod is installed (as it would be redundant).

https://mods.factorio.com/mod/ScanArea
